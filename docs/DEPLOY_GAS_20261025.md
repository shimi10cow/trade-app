# GAS のまとめてデプロイ（2026-10-25 の分）

この 1 枚の順番どおりに進める。全部で 20〜30 分。途中で迷ったら、その手順の番号でクラウドに聞く。
PC の EA は動かしたままでよい（デプロイ中の数分、EA の通信が失敗しても、PC が後で送り直す）。

---

## 0. 入るもの（何が変わるか）

- 古いコードの削除（旧 EA・旧取り込み・一度きりの移行の窓口）
- 起動の速さの直し（トレードと通貨ペアの一時保存）
- 取り込み：自動で紐付けない（全部が確認待ち）・ゴミ箱・戻す・候補の時間・**読む期間**・まとめる／紐付けのチェック・決済だけ届いた約定を元のトレードにつなぐ
- 予約の**シグナルのみ**、EA の**最小ロット**（PC の EA の入れ替えも要る。手順 7）
- 通貨ペアの**データを送信**（表「Pair_History」）
- 予約＝裁量の記録、損切り 4 択、Telegram 停止の書き込み ほか（OPEN_ITEMS の A1 の分）

---

## 1. 3 つのファイルを貼り直す

1. スプレッドシート → 「拡張機能」→「Apps Script」
2. GitHub の main から、次の 3 つを**それぞれ全部コピーして、全部置き換える**（Ctrl+A → 貼り付け）

   | Apps Script のファイル | GitHub のファイル |
   |---|---|
   | `コード.gs`（または `Code.gs`） | `Code.gs`（リポジトリの一番上） |
   | `EA_Live` | `gas/EA_Live.gs` |
   | `Trades` | `gas/Trades.gs` |

   GitHub では、ファイルを開いて右上の「Copy raw file」（四角が 2 つのボタン）でコピーできる
3. 左の一覧に **`EA_API`** というファイルがあれば削除する（どこからも使っていない。無ければ何もしない）
4. Ctrl+S で保存。赤いエラーが出ないこと

## 2. 新しいバージョンでデプロイ（URL を変えない）

1. 右上「デプロイ」→「デプロイを管理」
2. 今のデプロイの**鉛筆（編集）**→「バージョン」で**「新バージョン」**→「デプロイ」
3. **「新しいデプロイ」は押さない**（URL が変わってアプリも PC もつながらなくなる）

## 3. アプリで入ったことを確かめる（スマホでアプリを開き直す）

- MT5 タブ →「取り込みの設定」に**「読む期間」**が出る
- EA 設定タブ → 通貨ペアの「＋予約」→ 一番上に**「種類：実エントリー／シグナルのみ」**が出る
- 通貨ペアタブ →「データを送信」を押す →「直近 1 日に更新したペアはありません」か、送る確認が出る（「GAS をデプロイすると使えます」と出たら、手順 2 がまだ）
- ホーム・履歴・分析がいつもどおり出る。2 回目以降の起動が前より速い

## 4. 前に自動で結び付いた 4 件を戻す（1 回だけ）

1. エディタ上の関数の選択で **`impRevertAutoLinksOnce`** を選んで「実行」（試し。何も変えない）
2. 下の「実行ログ」を見る
   - `"count": 4` 前後と、4 件のペア・向き・エントリー日時
   - `"tradesActive"`：`false` なら各行の `source` が「なし（結び付きだけ外す。今の値: …）」になる。**この「今の値」は MT5 が書いた値**なので、スクショかメモを残しておく（外した後、手入力の値に直したい時に使う）
   - `true` なら「Entries（元の値を戻す）」
3. よければ **`impRevertAutoLinksApply`** を実行 → MT5 タブの「確認が必要なトレード」に 4 件が戻る
4. 4 件それぞれ、MT5 タブで「記録にする」／正しい手入力のトレードに紐付け（候補に出なければ「ほかの手入力トレードを選んで紐付け」）／🗑️

## 5. 10/25 に間違えて「記録にする」を押した 1 件を戻す

- MT5 タブ →「最近記録にしたもの」→ そのトレードの**「確認待ちに戻す」**
- 一覧に無ければ（14 日を過ぎた時）、履歴でそのトレードを開き、上の「MT5 取り込み」の欄の**「確認待ちに戻す」**

## 6. 表を「Trades」に切り替える（OPEN_ITEMS の A2。手順 4・5 の後）

1. 関数 **`upgradeSheetsOnce`** を実行（最初にスプレッドシートを丸ごとバックアップする）
2. 実行ログで「Trades: ○件、損益 ○（Entries ○件、○）」の件数と損益が同じこと
   - 数が合わない時は自動で止まり、アプリは今のまま（Entries）。ログをクラウドに渡す
3. アプリを開き直して、履歴の件数・今月の損益がいつもと同じこと
4. 戻したい時は関数 `switchBackToEntries`（Entries は何も変わっていない）

## 7. PC の EA を入れ替える（デスクトップの Claude に頼む）

デスクトップに次のように伝える：

> main を `git pull` して、デモと本番の EA を「新EA 更新」で入れ替えて。取り込みのボタン（`IMPORT_MT5.bat`）は変えなくてよい。終わったら Telegram の `/status` で両方から返事が来るかと、ログにエラーが無いかを見て。

入れ替え後、数分でアプリの EA 設定タブの**「最小ロット」**が押せるようになる（PC が「対応している」と知らせてくるまでは薄い表示のまま）。
シグナルのみの予約も、入れ替えた PC だけが受け取る（古い PC の間は待機のまま。注文はしない）。

## 8. まだなら（OPEN_ITEMS の A3）

- エディタの「トリガー」（時計のマーク）→ `eaWatchdog` を 1 時間ごと
- 「プロジェクトの設定」→ スクリプト プロパティに `TELEGRAM_BOT_TOKEN` と `TELEGRAM_CHAT_ID`
- PC が 2 時間止まった時の通知と、毎日の EA_Health（バックテストとの比較）が動く

## うまくいかない時

| 症状 | 見る所 |
|---|---|
| アプリが「通信できません」・何も出ない | 手順 2 で「新しいデプロイ」を作っていないか（URL が変わる）。作ってしまったら、そのデプロイを「アーカイブ」して、元のデプロイを新バージョンにする |
| 保存時に赤いエラー | どのファイルの何行目か。貼り付けが途中で切れていないか（ファイルの最後の行まで入っているか） |
| 「key not set up」 | 関数 `eaSetupKeys` がまだ（前にやっていれば出ない） |
| EA タブの「最小ロット」がずっと薄い | 手順 7 の入れ替えがまだ、か PC の EA が止まっている（EA タブの「最終通信」の時刻を見る） |
