## クラウドの担当（クラウドだけが書き換える）

- `research/`（研究のコードと結果）
- 検証の結果を書く資料（研究のまとめ、`research/INSTRUMENT_PROFILES.md` など）
- 一致テストの道具：`mt5_ea/live/tests/`

## デスクトップの担当（上以外ぜんぶ）

- EA 本体：`mt5_ea/live/`（`tests/` 以外）。**売買の判断・損切り・ロットの計算を変えるとき**は、変えたあと一致テストをクラウドに頼む（何を変えたか、どの EA に効くかを書いて渡す）
- PC で動かす仕組み：`mt5_ea/` の bat・ps1（起動・停止・更新・取り込みのボタン）
- アプリ：`index.html`・`app.js`・`ea_live.js`・`mt5_tab.js`・`style.css`・`sw.js`・`manifest.json` ほか
- 裏側：`gas/`・`Code.gs`
- 資料：`docs/`（`EA_LIVE_SETUP.md`・`EA_PC_OPERATION.md`・`OPEN_ITEMS.md` ほか）
- 古い EA のファイルの整理（`docs/OPEN_ITEMS.md` の C1）

## 進め方

- **デスクトップ**
  - 作業の前に `git pull` で main を最新にする。小さな直しは main へ直接、まとまった直しはブランチ → PR
  - EA を入れ替えるときは「新EA 更新」（動いている EA を止める → main を取る → 起動し直す）
- **クラウド**
  - `research/` と検証の資料だけを直す。EA 本体やアプリを直したくなったら、内容をユーザー経由でデスクトップに渡す
  - 検証の結果で EA の変更が必要になったら、「何を・なぜ・どの EA に」を `docs/OPEN_ITEMS.md` の D に書いて渡す
- **担当が決まっていない新しいファイル**：検証・研究ならクラウド、それ以外はデスクトップ。迷ったらユーザーに聞く
