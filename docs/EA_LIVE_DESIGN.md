# 本番 EA の作り方（2026-10-24、作業の 2 番目「ロジックの作り直しと一致テスト」）

## 方針

- 研究のコードをそのまま本番に持っていくのではなく、研究と同じ計算をする「本番用の部品」を作り、同じ部品で過去データも流せるようにする
- 足が確定するたびに、銘柄ごとに直近のデータ（数千本）だけで計算し直す。研究の結果と同じトレードが出るかを EA ごとに確かめる（一致テスト）
- 一致テストは 2 つ
  1. 全期間で流した結果が、研究のトレード一覧（エントリーの時刻・向き・損切り・決済）と一致する
  2. 途中で区切ったデータ（その時点までしか知らない状態）で流しても、区切りより前のトレードが変わらない（未来のデータを使っていないことの確認）

## 確認済み：土台のダウ判定（dow_window_test.py）

- 途中から計算を始めても、M15・H1・H4 とも 100〜200 本で全期間の計算と完全に一致する（主要・仮のトレンドとも一致率 100%）
- 計算時間：直近 6,000 本で 0.1 秒（全期間 14.6 万本は 57 秒）→ 足が確定するたびに直近だけ計算すれば十分速い
- 長い MA（H4 の SMA1200＝日足 SMA200 相当）を使う EA があるので、H4 は 3,000 本（約 2 年）を使う

## 進める順番

1. 部品の土台：データ（MT5 の足、サーバー時間のまま）、足の作り直し（M15→H1・H4・日足）、ダウ判定、ATR・MA
2. EA を 1 本ずつ移す → 一致テスト 1・2 を通す。新しい順（右肩 → RSI2 → Q → S → C・J2 → R・T・L・A）
3. 全部そろったら、19 本をまとめて過去に流し、組み合わせの成績（§106）が再現されるかを見る

## 本番の動かし方で分かったこと

- 計算は直近 600 日（R だけ 1,100 日）の M15 で行い、最初の 250 日は状態を作るだけにする。こうすると「前から持っているポジションがあるので入らない」も全期間の計算と同じになる
- 研究では「全部の候補で計算してから絞る」順番の EA がある（右肩の押し 4ATR 以上・買いだけ、ドル円 C の強いラインだけ、T2 の横軸、L2 の抵抗、BTC の平日だけ）。本番も同じ順番で計算し、注文するのは絞った後のものだけにする（絞られた候補も、計算の中ではその向きの枠を使う）
- 足が確定するたびに計算し直し、計算の最後に残っている保有ポジションとその損切りの位置を、そのまま MT5 の注文と損切りに合わせる。新しく入るのは「直前に確定した足でシグナルが出たもの」だけ（PC が止まっていた間の分には入らない）
- R（EA-R）は「過去のシグナルの強さの上位 25% を見送る」条件があり、2003 年からの全部のシグナルと比べている。本番では長い履歴で 1 回計算した記録を引き継いで使う（作業の 3 番目で作る）
- RSI(2) は研究どおり「日足の終値で入る」。本番では終値ちょうどには入れないので、取引が終わる直前（サーバー時間 23:45〜23:55）に、その時の値段を終値とみなして判定し、成行で入る。決済も同じ時刻に判定する。15 分前の値で判定した場合の成績は終値とほぼ同じ（§109）。終わり際はスプレッドが広がることがあるので、デモで実際の約定値とスプレッドを確かめる
- C と L は研究と同じく、ラインの始点に「あとで位置が直ったスイングの最終的な位置」を使っている。テスト 2 で本番との差を確かめる
