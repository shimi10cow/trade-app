# 自宅 PC での EA の動かし方（2026-10-24〜、PC の担当）

置き場所：`C:\Users\81805\Documents\EA261024\trade-app`（GitHub の clone）
記録とログ：`C:\Users\81805\TradeEA_data`（プログラムを入れ替えても消えない）

## デスクトップのボタン

| ボタン | すること |
|---|---|
| 新EA デモ START | EA を起動する。黒いウィンドウが「見張り役」 |
| 新EA デモ STOP | EA を止める（保有中のポジションの損切りは MT5 のサーバー側に残る） |
| 新EA デモ 更新 | 止める → GitHub の main から最新を取る → 起動、を 1 回で |

ボタンが消えたら `mt5_ea\setup_live_ea_desktop.ps1` を右クリック →「PowerShell で実行」。

## 見張り役（START で開く黒いウィンドウ）がすること

- 起動時に確認：EA 用の口座か／サーバーにつながっているか／**アルゴ取引が ON か**（OFF なら赤字で警告。OFF のままだと注文が通らない）
- EA が止まったら自動で起動し直す（続けて失敗するときは 30 秒 → 最大 5 分まで間を空ける）
- MT5 が閉じたら MT5 を立ち上げ直し、EA もつなぎ直す（MT5 にパスワードを保存してあること）
- ウィンドウが開いている間は PC をスリープさせない（画面は消えてよい）
- 同じ口座の EA を 2 つ動かさない（2 回押しても断る）
- 記録：`watcher_demo.log`（見張り役）、`live_demo.log`（EA 本体）。20 MB を超えたら古い分を `.1` に回す

**ウィンドウの × を押すと EA が止まる。** 邪魔なら最小化しておく。

## PC の再起動・ログオン後に自動で起動（1 回だけ設定）

`mt5_ea\SETUP_LIVE_EA_AUTOSTART.bat` をダブルクリック → ログオンの 1 分後に、最小化した状態で START と同じものが動く。
やめるときは タスク スケジューラで「TradeEA live demo」を削除。

注意：
- Windows Update などで再起動したあと、**ログオンするまで EA は動かない**（パスワード入力の画面で止まる）
- ノート PC は**ふたを閉じるとスリープする**設定のことが多い。ふたを開けたままにするか、電源の設定で「ふたを閉じたときの動作」を「何もしない」にする
- PC が 2 時間止まったら、GAS の `eaWatchdog`（トリガーを入れていれば）が Telegram に知らせる

## 困ったとき

- 起動しない：黒いウィンドウの赤字を読む。`CONFIGURE_LIVE_EA.bat` の設定（GAS のアドレス・EA_KEY・口座番号）が無いと起動しない
- 別の口座で MT5 にログインしていると、EA は動かない（口座番号の確認）
- 注文が出ない：アルゴ取引の ON、アプリで「稼働」、EA のモードが自動か、を確認
