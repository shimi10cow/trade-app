## MT5 は口座ごとに 1 つ

MT5 は 1 つにつき 1 口座しかログインできない。EA はどの MT5 を使うかを、`terminal64.exe` の場所（`CONFIGURE_LIVE_EA.bat` で保存する設定）で決める。

| EA | 口座 | 使う MT5 |
|---|---|---|
| デモ | 75610829（XMTrading-MT5 3） | `C:\Program Files\XMTrading MT5`（`EA_DEMO_MT5_PATH`） |
| リアル | 370102382（XMTrading-MT5 2） | `C:\Users\81805\TradeEA\MT5_real`（`EA_REAL_MT5_PATH`、XM の MT5 をフォルダごとコピーしたもの） |

- どちらの MT5 でも**口座を切り替えない**（切り替えると、その EA は口座番号の確認で止まる）
- それぞれの MT5 でパスワードを保存し、**アルゴ取引ボタンを ON** にしておく
- それぞれの MT5 で「ツール」→「オプション」→「チャート」→**「チャートの最大バー数」を「Unlimited（無制限）」**にして、MT5 を開き直す。初期値（100000）のままだと 15 分足が約 1000 日分しか読めず、1100 日分を使う R@EURUSD が `no M15 history (Invalid params)` で動かない（新しくコピーした MT5 は初期値に戻っている）
- コピーは `AppData` の下に置かない（Claude のデスクトップアプリから作ると、Claude 専用の場所に振り替えられて、ボタンから見えなくなる）

## デスクトップのボタン

| ボタン | すること |
|---|---|
| 新EA デモ START / STOP | デモの EA を起動する／止める。START で開く黒いウィンドウが「見張り役」 |
| 新EA リアル START / STOP | リアルの EA を起動する／止める。START は押し間違い防止に `Y` の確認がある |
| 新EA 更新 | 動いている EA（デモ・リアル）を止める → GitHub の main から最新を取る → 同じものを起動し直す |
| EA用 MT5 リアル | リアル用の MT5 を開く（ログインやアルゴ取引の確認用） |

- STOP しても、保有中のポジションの損切り（と 2R の利確）は MT5 のサーバー側に残る
- ボタンが消えたら `mt5_ea\setup_live_ea_desktop.ps1` を右クリック →「PowerShell で実行」

## 見張り役（START で開く黒いウィンドウ）がすること

- 起動時に確認：EA 用の口座か／サーバーにつながっているか／**アルゴ取引が ON か**（OFF なら赤字で警告。OFF のままだと注文が通らない）
- EA が止まったら自動で起動し直す（続けて失敗するときは 30 秒 → 最大 5 分まで間を空ける）
- MT5 が閉じたら MT5 を立ち上げ直し、EA もつなぎ直す（MT5 にパスワードを保存してあること）
- ウィンドウが開いている間は PC をスリープさせない（画面は消えてよい）
- 同じ口座の EA を 2 つ動かさない（2 回押しても断る）
- 記録：`watcher_demo.log` / `watcher_live.log`（見張り役）、`live_demo.log` / `live_live.log`（EA 本体）。20 MB を超えたら古い分を `.1` に回す

**ウィンドウの × を押すと EA が止まる。** 邪魔なら最小化しておく。

## MT5 の取り込み（自分の 8 口座の履歴をアプリへ）

| ボタン | すること |
|---|---|
| MT5 取り込み | 前回の続きから読む（3 日分重ねて読む。初回は 90 日） |
| MT5 取り込み 90日読み直し | 直近 90 日を読み直す（同じ約定は二重に入らない） |
| 取り込み用 MT5 | 取り込み用の MT5 を開く（口座のログイン用） |

- 押すと取り込み用 MT5（`C:\Users\81805\TradeEA\MT5_import`）が 1 つ開き、口座を順に切り替えて読み、アプリへ送って、閉じる。EA は動いていても止まっていてもよい
- 口座の一覧：`TradeEA_data\import_accounts.json`（GitHub には上げない。全口座とも同じ MT5、server は口座のサーバー名）
- 口座を足すとき：取り込み用 MT5 でその口座に**投資家パスワード**でログインし「パスワードを保存」→ `import_accounts.json` に 1 行足す
- 記録：画面と `TradeEA_data\import.log`。最後の `GAS: {...}` が結果（新しい約定の数・手入力に紐付けた数・下書きの数）
- 「取り込み用 MT5 でこの口座のパスワードが保存されていない」と出た口座は、その口座だけ飛ばされる（ほかは続く）。取り込み用 MT5 でログインし直す
- 取り込み用 MT5 の音がうるさければ、その MT5 で「ツール」→「オプション」→「イベント」の「有効にする」を外す

## PC の再起動のあと

自動では起動しない（自分で START を押す、と決めている）。PC を再起動したら、ログオンして START を押す（デモ・リアルそれぞれ）。

注意：
- ノート PC は**ふたを閉じるとスリープする**設定のことが多い。ふたを開けたままにするか、電源の設定で「ふたを閉じたときの動作」を「何もしない」にする
- PC が 2 時間止まったら、GAS の `eaWatchdog`（トリガーを入れていれば）が Telegram に知らせる

## 困ったとき

- 起動しない：黒いウィンドウの赤字を読む。`CONFIGURE_LIVE_EA.bat` の設定（GAS のアドレス・EA_KEY・口座番号・MT5 の場所）が無いと起動しない
- 別の口座で MT5 にログインしていると、EA は動かない（口座番号の確認）
- 注文が出ない：アルゴ取引の ON、アプリで「稼働」、EA のモードが自動か、を確認
