# EA 運用システム：全体方針と決めたこと（2026-10-24）

研究で採用した EA（research/INSTRUMENT_PROFILES.md の「採用 EA の一覧」）を MT5 で動かし、Web アプリで操作・記録するための方針。
細かい設計はこの方針の上で、作りながら都度相談して決める（不要な機能は削る、UI が良くなるなら作り替える）。

## 全体の形

```
[自宅 PC]  MT5（XM 極・EA 専用口座）＋ EA 本体（Python）
   ├ ロジック：採用 EA（研究のコードを確定足ごとに回して判定）
   ├ 注文・リスク・安全装置
   └ 数分ごとに「生きている・口座の状態」を送る
        │
[裏側]  窓口（API）＋データの置き場（当面 Google Apps Script＋スプレッドシートを整理して使う）
        │
[アプリ] EA の ON/OFF・全体停止・リスク設定／口座の推移と DD／EA ごとの成績とバックテストの比較／裁量トレードの記録
[Telegram] 通知・緊急停止の予備
```

## 決めたこと

| 項目 | 決定 |
|---|---|
| EA を動かす場所 | 自宅の PC（停止対策：損切りは必ず XM のサーバー側に置く、自動起動・自動再起動、生存確認が途切れたら Telegram で通知、再起動時に MT5 のポジションと照合） |
| 古いロジック（M15 ストキャス版） | 採用 EA に置き換える |
| 口座 | EA 専用の極口座を作り、裁量トレードの口座と分ける |
| 口座の通貨 | 円 |
| 保有中のポジション | MT5 のアプリで見る（アプリでは作り込まない） |
| 履歴 | どの EA が、何を理由に入ったかが分かる形で残す（EA 名・銘柄・向き・入った理由の数値・エントリー／損切り／決済の価格と時刻・R・損益・ロット倍率・EA のバージョン） |
| チャート画像 | 残さない（MT5 で見られる。振り返りは価格と時刻から Claude で描き直せる） |
| 止める基準 | 引っかかったら通知だけ（止めるかは自分で判断） |
| アプリの書き込み | 設定変更・停止などの書き込みには合言葉（鍵）を付ける |
| ロット・リスク | 運用前に決める（候補：普段 1.0%＋DD10% で半分、月初 3 日とゴールドの金曜の買いは 1.5 倍。最小ロットの制約あり） |

## 後で決めること（おすすめの初期案）

- PC が止まっていた間のシグナル：再起動後は見逃したエントリーには入らず、保有中の管理だけ再開する
- ロジックを直したとき：EA ごとにバージョン番号を付け、デモで確かめてから本番に入れる
- デモの期間と本番に進む条件：例 2 か月、一致テストの再確認と、勝率・平均 R がバックテストの範囲内
- Telegram の通知：エントリー・決済・エラー・EA の停止・止める基準に近づいた時
- 裏側をデータベース（Supabase など）に移すか：通信の遅さで困ったら検討。表の作りを先に整理しておく

## 進める順番

1. 設計書（データの表、EA と裏側のやり取り、画面の構成）
2. ロジックの作り直しと一致テスト（過去データを流してバックテストと同じトレードが出ることを EA ごとに確認。合うまで本番に進まない）
3. 注文・リスク・安全装置の更新（1%・DD10% で半分・暦の倍率・最小ロット・同時保有の上限・EA ごとのマジックナンバー）
4. 裏側とアプリの作り直し（画面ごとにファイルを分ける。今の裁量の記録機能は移植）
5. デモ口座で 1〜3 か月、バックテストと比較
6. 少額（30 万円程度）で本番

## アプリの方針（2026-10-24 決定）

- 裏側はスプレッドシートのまま表を整理する。起動時は直近だけ読み込み、古いデータは必要な時だけ読む
- EA の記録は実際に入ったトレードだけ（見送ったシグナルは残さない）
- 裁量と EA のトレードは同じ形の表にまとめ、「どこから来たか」で区別する
- アプリのコードは画面ごとにファイルを分ける（今は app.js 1 本に約 7,000 行）。見た目と使い勝手も作り直してよい
- 記録の入力項目は今のまま残す（根拠のスコア・ダウルール・指標前エントリー・再エントリー・画像・音声入力）。データが溜まったら見直す
- アプリの中で AI を呼ぶ機能（Groq の AI 分析）は削る。深い分析はデータを書き出して後で Claude などに渡す
- ギャラリーは独立した画面をやめ、画像はメモとトレードに付ける。トレード一覧を画像表示に切り替えられるようにする
- メモは残す（タグと画像を付けられるシンプルなメモ帳）
- レビューは振り返り（反省と次の約束）＋成績の自動集計（裁量・EA 別）を中心にする。ルールどおりかはスコアで見る。型ごとの検証は書き出したデータで後から行う
- 画像は Google ドライブに置き、GAS を通さずサムネイル用のアドレス（drive.google.com/thumbnail?id=…&sz=w…）で直接表示する。アップロード前にアプリ側で長い辺 1,600px 程度に縮める。作り直しの最初に過去の画像で表示の試験をしてから採用する
  - 今の作りは GAS が 1 枚ごとにドライブから取り出して文字データで返すため、遅く、3MB 超は表示できない

## アプリの見た目（2026-10-24 決定）

- 見た目・タブ・ホームは今のアプリのまま（タブ：ポジション／通貨ペア／分析／MT5／EA 設定。通貨ペアは毎週使うのでタブに残す）
- 変えるのは機能：EA 設定タブの作り直し（EA×銘柄ごとの ON/OFF・全体停止・リスク・バックテストとの比較）、分析に EA を追加、並び替え・絞り込みを見やすく
- 右上の「EA 稼働中」などの常時表示は付けない
- トレードの表示は今と同じく、テキストを全部見せる
- コードの分割は見た目を変えずに行う
- 新しい見た目の試作（https://claude.ai/artifact/DKHkUaPMsLSf22ur23zujZ）は不採用。参考として残すだけ

## 追加で決まったこと（2026-10-24）

- EA ホームのシグナルの時刻ずれ：原因は EA 本体が MT5 の足の時刻（XM サーバー時間＝Europe/Athens）を世界標準時として送っていること（main.py の datetime.fromtimestamp(sig_ts, timezone.utc)）。アプリで日本時間に直すと 2〜3 時間ずれる。新しい EA 本体ではサーバー時間を正しく変換する
- 分析：裁量と EA を見分けやすくする。並び替えは押すと見た目が切り替わるボタンにする。細かい見た目（削除ボタンの大きさなど）は最後にまとめて直す
- 履歴タブに「EA」のタブを足し、EA の結果はそこで見る
- メモはホーム右上のまま残す
- EA の自動チャート設定は削る
- EA 設定タブは通貨ペアごとではなく EA ごと（EA と銘柄は決まっている）。各 EA の稼働モード（自動売買／通知のみ／停止）、全体停止、リスク設定
- 予約エントリー（新機能）：裁量で分析し、入るところだけ EA 口座で自動にする
  - きっかけ：M15 のストキャス、H1 のストキャス（条件の細部は確認中）
  - 損切り・決済：価格を指定できる（指定しなくてもよい）
  - 有効期限：なし（取り消すまで）
  - ロット：予約ごとに選ぶ（口座の %／最大損失額／ロット直接）
  - 通常の EA とは別のマジックナンバーで管理し、成績も「予約」として分ける。ホームに「予約中」と「予約から入ったポジション」を出す
- MT5 の取り込み（約 8 口座）：口座ごとの MT5 のコピーに一度ずつログインし、取り込み係が順番に読む（ボタン 1 回または 15 分ごと）。読み取り専用の投資家パスワードを使う。手入力のエントリーと自動で紐付け、相手がない取引は下書きを作る
- 分けて入ったポジションの合算：同じ銘柄・同じ向き・近い時間のポジションを 1 トレードにまとめる（合計ロット、ロットの重み付き平均の建値・決済値、合計損益、合計リスクで割った R）。手で「まとめる・分ける」を直せる（範囲と時間の幅は確認中）
