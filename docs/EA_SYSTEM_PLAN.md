# EA 運用システム：全体方針と決めたこと（2026-10-24）

研究で採用した EA（research/INSTRUMENT_PROFILES.md の「採用 EA の一覧」）を MT5 で動かし、Web アプリで操作・記録するための方針。
細かい設計はこの方針の上で、作りながら都度相談して決める（不要な機能は削る、UI が良くなるなら作り替える）。

## 全体の形

```
[自宅 PC]  MT5（XM 極・EA 専用口座）＋ EA 本体（Python）
   ├ ロジック：採用 EA（研究のコードを確定足ごとに回して判定）
   ├ 注文・リスク・安全装置
   └ 数分ごとに「生きている・口座の状態」を送る
        │
[裏側]  窓口（API）＋データの置き場（当面 Google Apps Script＋スプレッドシートを整理して使う）
        │
[アプリ] EA の ON/OFF・全体停止・リスク設定／口座の推移と DD／EA ごとの成績とバックテストの比較／裁量トレードの記録
[Telegram] 通知・緊急停止の予備
```

## 決めたこと

| 項目 | 決定 |
|---|---|
| EA を動かす場所 | 自宅の PC（停止対策：損切りは必ず XM のサーバー側に置く、自動起動・自動再起動、生存確認が途切れたら Telegram で通知、再起動時に MT5 のポジションと照合） |
| 古いロジック（M15 ストキャス版） | 採用 EA に置き換える |
| 口座 | EA 専用の極口座を作り、裁量トレードの口座と分ける |
| 口座の通貨 | 円 |
| 保有中のポジション | MT5 のアプリで見る（アプリでは作り込まない） |
| 履歴 | どの EA が、何を理由に入ったかが分かる形で残す（EA 名・銘柄・向き・入った理由の数値・エントリー／損切り／決済の価格と時刻・R・損益・ロット倍率・EA のバージョン） |
| チャート画像 | 残さない（MT5 で見られる。振り返りは価格と時刻から Claude で描き直せる） |
| 止める基準 | 引っかかったら通知だけ（止めるかは自分で判断） |
| アプリの書き込み | 設定変更・停止などの書き込みには合言葉（鍵）を付ける |
| ロット・リスク | 運用前に決める（候補：普段 1.0%＋DD10% で半分、月初 3 日とゴールドの金曜の買いは 1.5 倍。最小ロットの制約あり） |

## 後で決めること（おすすめの初期案）

- PC が止まっていた間のシグナル：再起動後は見逃したエントリーには入らず、保有中の管理だけ再開する
- ロジックを直したとき：EA ごとにバージョン番号を付け、デモで確かめてから本番に入れる
- デモの期間と本番に進む条件：例 2 か月、一致テストの再確認と、勝率・平均 R がバックテストの範囲内
- Telegram の通知：エントリー・決済・エラー・EA の停止・止める基準に近づいた時
- 裏側をデータベース（Supabase など）に移すか：通信の遅さで困ったら検討。表の作りを先に整理しておく

## 進める順番

1. 設計書（データの表、EA と裏側のやり取り、画面の構成）
2. ロジックの作り直しと一致テスト（過去データを流してバックテストと同じトレードが出ることを EA ごとに確認。合うまで本番に進まない）
3. 注文・リスク・安全装置の更新（1%・DD10% で半分・暦の倍率・最小ロット・同時保有の上限・EA ごとのマジックナンバー）
4. 裏側とアプリの作り直し（画面ごとにファイルを分ける。今の裁量の記録機能は移植）
5. デモ口座で 1〜3 か月、バックテストと比較
6. 少額（30 万円程度）で本番

## アプリの方針（2026-10-24 決定）

- 裏側はスプレッドシートのまま表を整理する。起動時は直近だけ読み込み、古いデータは必要な時だけ読む
- EA の記録は実際に入ったトレードだけ（見送ったシグナルは残さない）
- 裁量と EA のトレードは同じ形の表にまとめ、「どこから来たか」で区別する
- アプリのコードは画面ごとにファイルを分ける（今は app.js 1 本に約 7,000 行）。見た目と使い勝手も作り直してよい
- 記録の入力項目は今のまま残す（根拠のスコア・ダウルール・指標前エントリー・再エントリー・画像・音声入力）。データが溜まったら見直す
- アプリの中で AI を呼ぶ機能（Groq の AI 分析）は削る。深い分析はデータを書き出して後で Claude などに渡す
- ギャラリーは今のまま残す（画像はメモとトレードにも付けられる）
- メモは残す（タグと画像を付けられるシンプルなメモ帳）
- レビューは振り返り（反省と次の約束）＋成績の自動集計（裁量・EA 別）を中心にする。ルールどおりかはスコアで見る。型ごとの検証は書き出したデータで後から行う
- 画像は Google ドライブに置き、GAS を通さずサムネイル用のアドレス（drive.google.com/thumbnail?id=…&sz=w…）で直接表示する。アップロード前にアプリ側で長い辺 1,600px 程度に縮める。作り直しの最初に過去の画像で表示の試験をしてから採用する
  - 今の作りは GAS が 1 枚ごとにドライブから取り出して文字データで返すため、遅く、3MB 超は表示できない

## アプリの見た目（2026-10-24 決定）

- 見た目・タブ・ホームは今のアプリのまま（タブ：ポジション／通貨ペア／分析／MT5／EA 設定。通貨ペアは毎週使うのでタブに残す）
- 変えるのは機能：EA 設定タブの作り直し（EA×銘柄ごとの ON/OFF・全体停止・リスク・バックテストとの比較）、分析に EA を追加、並び替え・絞り込みを見やすく
- 右上の「EA 稼働中」などの常時表示は付けない
- トレードの表示は今と同じく、テキストを全部見せる
- コードの分割は見た目を変えずに行う
- 新しい見た目の試作（https://claude.ai/artifact/DKHkUaPMsLSf22ur23zujZ）は不採用。参考として残すだけ

## 追加で決まったこと（2026-10-24）

- EA ホームのシグナルの時刻ずれ：原因は EA 本体が MT5 の足の時刻（XM サーバー時間＝Europe/Athens）を世界標準時として送っていること（main.py の datetime.fromtimestamp(sig_ts, timezone.utc)）。アプリで日本時間に直すと 2〜3 時間ずれる。新しい EA 本体ではサーバー時間を正しく変換する
- 分析：裁量と EA を見分けやすくする。並び替えは押すと見た目が切り替わるボタンにする。細かい見た目（削除ボタンの大きさなど）は最後にまとめて直す
- 履歴タブに「EA」のタブを足し、EA の結果はそこで見る
- メモはホーム右上のまま残す
- EA の自動チャート設定は削る
- EA 設定タブは通貨ペアごとではなく EA ごと（EA と銘柄は決まっている）。各 EA の稼働モード（自動売買／通知のみ／停止）、全体停止、リスク設定
- 予約エントリー（新機能）：裁量で分析し、入るところだけ EA 口座で自動にする
  - きっかけ：M15 のストキャス、H1 のストキャス（今の EA と同じ判定：Stochastic 14,5,3）
  - 損切り・決済：価格を指定できる（指定しなくてもよい）
  - 有効期限：なし（取り消すまで）
  - ロット：予約ごとに選ぶ（口座の %／最大損失額／ロット直接）
  - 通常の EA とは別のマジックナンバーで管理し、成績も「予約」として分ける。ホームに「予約中」と「予約から入ったポジション」を出す
- MT5 の取り込み（約 8 口座）：口座ごとの MT5 のコピーに一度ずつログインし、取り込み係が順番に読む（ボタン 1 回または 15 分ごと）。読み取り専用の投資家パスワードを使う。手入力のエントリーと自動で紐付け、相手がない取引は下書きを作る
- 分けて入ったポジションの合算：同じ銘柄・同じ向き・近い時間のポジションを 1 トレードにまとめる（合計ロット、ロットの重み付き平均の建値・決済値、合計損益、合計リスクで割った R）。手で「まとめる・分ける」を直せる
  - 口座をまたいでもまとめる。決済までに追加した分も同じトレードに入れる
  - 時間の幅は初期値 24 時間（今の App_Settings の groupHours を引き継ぐ）、アプリの設定から変えられる

## スプレッドシートの表（2026-10-24 決定）

今の約 20 枚を約 10 枚にまとめる。中心は「全トレードの表（Trades）」と「MT5 の約定そのままの表（Executions）」。

| 新しい表 | 今の表 | 扱い |
|---|---|---|
| Trades | Entries | 作り直す。裁量・MT5 取り込み・EA・予約を全部入れ、Source で区別 |
| Executions | MT5_Executions | 1 行＝約定 1 回。列を約 20 に絞る |
| EA_Config | EA_Settings（通貨ペアごと） | 1 行＝1 EA に作り直す |
| Reservations | なし | 新規（予約エントリー） |
| EA_Status | なし | 新規（生存確認は端末ごとに 1 行を上書き、口座の推移は 1 日 1 行） |
| EA_Log | EA_Errors | 引き継ぐ。90 日より古い分は消す |
| Pairs | Pairs | 残す。EA 用の列（EA許可BUY/SELL・TL推進環境・TL逆トレ環境・EA環境確認日時・EA許可方向）は消す |
| Reviews | Reviews | そのまま |
| Memos | メモ＋Ideas | 1 つにまとめる |
| App_Settings | App_Settings | そのまま（groupHours・全体停止もここ） |
| EA_Calendar_Reminders | 同じ | 使っていれば残す |
| 保存用の別ファイルへ移す | EA_Signals・EA_Replay_Requests・MT5_Import_Requests・データ分析・集計・単利複利・パラメータ・手法 | アプリはこれらを読んでいない（成績はアプリ側で計算）。シートも直接は見ていない |

### Trades の列

- 基本：TradeID・Source（手入力／MT5 取り込み／EA／予約）・Status（下書き／保有中／決済済み）・Symbol（「EURUSD」などの名前で統一）・Direction・Accounts
- 価格と時刻：EntryTime・EntryPrice・SLPrice・TPPrice・ExitTime・ExitPrice・Lot（合計）
- 結果：Profit（円）・Swap・Pips・RiskJPY・R（損切り pips は価格から計算するので持たない）
- EA：EAName・EAVersion・Magic・LotMult・Reason（入った理由の数値を 1 列にまとめる）
- 裁量の記録：根拠のスコア・ダウルール・指標前エントリー・再エントリー・メモ（音声入力含む）などは今のまま
- 画像：EntryImages・ExitImages・PreImages（ドライブのファイル ID をカンマ区切り。今の 9 列を 3 列に）
- まとめ：MergeMode（自動／手動）・ExecCount（中身は Executions の TradeID で辿る）
- 管理：CreatedAt・UpdatedAt
- 残す：認識 OK の列（後の振り返りでダウの認識が合っていたかを見るため）
- 消す：エントリー前のチェックリスト（✅ 列）・ルール準拠 pips／損益・PairName（元）と Pair の重複・損切りの重複列・空の列・古い MT5 連携用の列（MT5SyncKey など）

### Executions の列

ExecID（口座番号＋約定番号。あれば二重に書かない）・Account・PositionID・Deal・Symbol・Direction・In/Out・DealTime・DealPrice・Volume・Profit・Swap・Commission・SL・TP・Magic・Comment・TradeID・ImportedAt。
分けて入った分や追加分も別の行で残るので、合算や手での「まとめる・分ける」をやり直せる。

### EA まわり

- EA_Config：EAID（例 DS@XAUUSD）・稼働モード（自動売買／通知のみ／停止）・リスク %・マジックナンバー・バージョン・UpdatedAt。EA は 1 分ごとにこの表を読む（アプリから EA への命令用の表は作らない）
- Reservations：予約 ID・銘柄・向き・きっかけ（M15／H1 ストキャス）・SL・TP・ロットの決め方と値・状態（待機／約定／取消）・入ったトレードの TradeID

### 重さ・長く使うための決まり

- 1 枚の表で運用し、アプリは直近の行だけ読む（年ごとの分割はしない。行数はトレードで年千行規模）
- 数式で集計するシートは置かない（書き込みのたびに再計算されて重くなる）
- EA・取り込み係・アプリの同時書き込みは GAS 側で順番待ち（LockService）
- 時刻は日本時間＋時差つき（例 2026-10-24 21:15+09:00）で統一
- 表どうしは行番号ではなく文字の ID でつなぐ

### 移し替え

ファイルを丸ごとコピーして保管 → 新しい表を横に作りスクリプトで変換 → 件数と損益の合計が一致するか確認 → アプリを切り替え → 古い表は 1 か月残してから消す。

## EA と裏側のやり取り（2026-10-24 決定）

- 通信は 5 分に 1 回にまとめる：EA が生存確認と口座の状態を送り、返事で EA 設定と予約を受け取る（1 日 288 回。1 分ごとに読むより軽い）
- 加えて M15 の足が確定する直前にも 1 回読む（直前に入れた予約を取りこぼさない）
- 生存確認は端末ごとに 1 行を上書きする（行は溜まらない）。口座の推移だけ 1 日 1 行足す
- トレードの記録は、入った時と決済した時に送る
- 急ぎの停止は Telegram から（すぐ効く）。アプリからの停止は最大 5 分遅れてよい
- PC が止まっていないかは GAS が 1 時間ごとに最後の通信時刻を見る（急がないので軽くする）
- 通信が切れた時：EA は送れなかった分を PC に貯め、つながったら後から送る。トレードは止めない
- 合言葉（鍵）：EA 用とアプリ用を別にする。スマホは最初に 1 回入力すれば端末に保存されて以後は聞かれない。EA は PC の設定ファイルに書く。鍵はアプリのコードには書かない

## 通知の決まり（2026-10-24 決定：うるさくしない）

- すぐ届くもの：EA が自分で止まった時、止める基準に引っかかった時（1 回だけ）、注文や損切りの設定に失敗した時
- PC が止まった時：気づいた時に 1 回と、戻った時に 1 回だけ（繰り返さない）
- 同じエラーは繰り返し送らない。小さなエラーは記録だけ残し、アプリで見られるようにする
- エントリー・決済の通知は種類ごとにアプリで ON/OFF できる
- 急ぎの停止は Telegram から必ずできるようにする（これだけは確実に）

## 画面ごとの変更（2026-10-24 案。見た目・タブは今のまま）

- ポジション（ホーム）：今の表示は残す。「予約中」と「予約から入ったポジション」を足す。EA のシグナル表示は「EA」という表示に置き換え（中身は EA が入ったトレード）、時刻は日本時間で正しく出す。右上のメモは残す
- 通貨ペア：今のまま残す（毎週使う。分析チェックも毎週手で入れているので残す）。「EA 環境認識」の欄（TL 推進・TL 逆トレの ↑↓なし）だけ消す
  - 分析チェックとダウルール候補の選択は、今はスマホのブラウザの中だけに保存されている（消える・他の端末で見えない）。Pairs の表に 1 列足して保存する案（確認中）
- 分析：すべて／裁量／EA／予約の切り替え、EA ごとの成績とバックテストの比較、EA 口座の推移と DD を足す。グラフの文字の重なりと並び替えボタンを直す。AI トレード分析は消す。履歴に「EA」タブを足す
- MT5：取り込み（ボタン／15 分ごと）、口座ごとの最終取り込み時刻、相手のない取引の下書き一覧、まとめる・分ける
- EA 設定
  - EA ごとのカード：稼働モード（自動売買／通知のみ／停止）・リスク
  - 通貨ペアごとの欄は残し、そこに予約エントリー（M15／H1 ストキャスで入る）を付ける
  - 全体停止・通知の ON/OFF（Entry・Exit・Error）・まとめる時間は残す
  - 消す：全通貨設定・過去シグナル取得・自動チャート設定・確認間隔の設定・Signal 通知
- エントリー入力：今の項目を残す（エントリー前の ✅ チェックリストだけ外す）。画像はドライブ＋サムネイル表示
- レビュー：今のまま。成績の自動集計を裁量と EA で分ける
- メモ：メモとアイデアを 1 つにまとめる
- 設定：合言葉を最初に 1 回入れる欄
- 軽くする工夫：起動時は直近 3 か月だけ読む。計算はスマホ側。画像は一覧ではサムネイルだけ

## 採用したものは全部 EA に入れる

採用 EA 16 本（research/INSTRUMENT_PROFILES.md の一覧）、月初 3 日とゴールドの金曜の買いの 1.5 倍、普段 1%＋DD10% で半分、ゴールドと US500 の右肩は買いだけ、BTC は平日だけ。過去データを流してバックテストと同じトレードが出るまで本番に進まない。
