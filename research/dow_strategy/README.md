## Wの定義をユーザーの目に合わせる（H4のW 51件を判定：○21・×レンジ14・×形6・×他9・△1）
○と×を一番よく分けたのは「AからBへの下げの速さ」（ATR/本、AUC0.70）。Cからネック割れの速さは差が出なかった。
簡単な条件：A→Bの速さ≥0.45ATR/本、AとCの差≤2ATR、Aの前90本で6ATR以上のトレンド → 通過したWの79%が○（元は42%）、○の71%を拾う。

|---|---|---|---|
| H4のW全部 | -6.8R PF0.83（70回） | +4.6R PF1.52 | +1.7R PF1.25 |
| **良いWのみ** | **+11.3R PF1.88 DD-3.5（31回）** | **+1.8R PF1.81（6回）** | **+2.4R PF2.70（4回）** |
| 主要＋仮転換＋良いW＋MA | +22.4R PF1.55 | -4.5R PF0.64 | -2.4R PF0.76 |
※判定に使ったWは2020・2021・2023年（開発期間内）。2025・2026年は判定に使っていない期間でもプラス。ただし回数が少ない（年6回程度）。
