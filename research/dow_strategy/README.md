## 長期：エントリー時の環境で分解（`long_features.py` → `results/long_breakdown_{i}.csv`）
- H4調整ラインブレイク中：2015年以降は良いが2003-2014は悪化（既存EA＋H4一致でPF 0.75）→ 長期では安定しない
- H4トレンド段階（転換後の高値/安値更新回数）：段階0（転換直後）と段階2は全期間区分でプラス、段階1と3回以上はマイナス寄り
  - 既存EAで段階0か2のみ：517回 +106R PF1.34 DD-25（2003-14 +31R / 2015-24 +65R / 2025-26 +10R）
  - ※全期間を見て選んだ条件なので過剰適合の可能性あり。段階1が悪く2が良い理由は未解明
- D1ダウ一致はむしろ成績が下がる。H4押し安値から4ATR以上離れた所のエントリーは弱い

## 未来参照チェック（`check_causal_long.py`）
- 2005年以降の既存EAトレード40件について、「その時点までのデータだけで計算」と「60日先までデータがある状態で計算」を比較
  → D1/H4/H1 のトレンド・押し安値/戻り高値・仮トレンド・段階・H4/D1ライン（ブレイク有無）・M15トレール用高安が**全件一致**
- 対照実験：わざと未来1日分を混ぜると8件中8件で差分が出る（＝チェックが機能している）
- 全期間の不変条件：押し安値/戻り高値が動いたのは全てダウイベントの足（H4 1069回・H1 4045回・D1 185回、例外0）、
  上昇中に終値が押し安値を下回ったまま／下降中に戻り高値を上回ったままの足は0
- エンジン本体：上位足は確定足のみ、トレール高安は確定の次の足から反映、エントリーはシグナル足の終値
- 押し安値/戻り高値の移動履歴：`results/protected_moves_{H4,H1,D1}.csv`（known_at＝判明した足の終値時刻）
