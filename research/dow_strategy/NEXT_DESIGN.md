# 次の検証の設計（2026-10-20、M15確認待ちの間に準備）

M15 の確認（MAルール）が終わったら、ここに書いた組み合わせをそのまま回す。検証結果はまだ出していない。

## 1. 共通の形：環境 × 場所 × タイミング × 損切り × 決済
EA を「部品の組み合わせ」で作る（`ea_core.py`）。同じ場所でもタイミングや損切りを変えれば別の EA になり、
同じ所でまとめて損切りされるのを避けられる（ユーザー方針：結果が良ければ条件は分岐させる）。

| 部品 | 選べるもの | 実装 |
|---|---|---|
| 環境 | 日足側（日足SMA200の推進側）／T環境（日足側＋ER高）／R環境（ER低＋H4 SMA200から伸び切っていない） | `env_ctx.py` |
| 場所（セットアップ） | 下の 2 章 | `setups.py`・`tl_ea.py`・`retest_ea.py` |
| タイミング | `dow`（M15仮トレンドの転換）／`stoch`（既存EAのストキャスの順番、MA条件なし）／**`ma`（M15確認後にユーザーのMAルールを追加）** | `ea_core.add_trigger()` |
| 損切り | 下の 3 章 | `ea_core.stop_ref()` |
| 決済 | `h1`（+act R 後に H1 の高安でトレール）／`m15`（M15の高安）／`hyb`（M15 で始め、+sw R から H1） | `ea_core.run()` |

## 2. 場所（推進を取るパターン。調整取りは後回し）
| 名前 | 定義（すべて未来を見ない） | 準備状況（2019-26 の件数） |
|---|---|---|
| L ライン3〜4点目 | 既存（tl_ea D2）。1つ目の押し 38〜62% 版も候補 | 済 |
| A H4転換リターン | 既存（retest_ea E1） | 済 |
| **F 押し目の深さ** | H4 の推進の波（押し安値 → その後の最高値）に対して 38.2 / 50 / 61.8% まで戻った所。押し安値は割っていないこと。波は 3ATR 以上 | 949 件（38.2: 411 / 50: 302 / 61.8: 236） |
| **P 押し安値だけ** | H4 押し安値（戻り高値）の ±0.5ATR まで戻った所（1回ごと、一度離れたら再度有効） | 308 件 |
| **W トレンド終わりのW** | 良い W（B への速さ・A と C の差・前の伸び）＝ retest の 'wq'。W は転換と決め打ち | 46 件 |

- 今後：H4 の水平帯が近い所（戻り高値とその上の高値）を「帯」として扱い、帯の上端で判断する形も検討

## 3. 損切りの候補（買いの場合。売りは逆）
| 名前 | 位置 | 2019-26 での幅の目安（中央値） |
|---|---|---|
| `m15turn` / `m15swing` | M15 ダウ転換の安値（直近の確定した M15 安値）の下 | 20〜40pips |
| `h1swing` | H1 ダウの直近安値の下 | 20〜60pips |
| `h1prot` | H1 の押し安値の下 | — |
| `h1ma75` / `h1ma200` | H1 SMA75 / SMA200 の下（入る時に価格より下にある時だけ） | 15〜50pips |
| `ref` | 場所そのもの（ラインの先・W の安値・H4 押し安値など） | F は 100pips 超と広い |
- それぞれ「その先に H1 ATR × buf ＋ pips」の余裕。細かい数値の当てはめはしない（buf は 0.5 / 1.0 の2択程度）
- 損切りがエントリーより上にある（H1 MA が価格の上など）時は入らない

## 6. M15確認後にやること（順番）
1. ユーザーの M15 MA ルールを `ma` タイミングとして追加（ea_core.add_trigger）
2. 場所（L / A / F / P / W / X）× タイミング（dow / stoch / ma）× 損切り（3章）を 2005〜2026 で一括実行
3. 日足側などの環境条件を付けて、5年ブロック全部プラスのものだけ残す
4. 残ったものを組み合わせ、相関・同時損切り・DD で選ぶ
5. 決済の切り分け（4章）は合図をもらってから

## 7. 通貨ペアの進め方（2026-10-20 判断）
- 今すぐ他通貨を「確認用」に入れる。ただし通貨ごとに条件を調整はしない（共通ルールの確認だけ）
- 開発は EURUSD、確認は他通貨。EURUSD で何かを足したら、毎回 他通貨でも崩れないかを見る
- 順番：USDJPY（元EAで通用＝比較しやすい）→ GBPUSD・AUDUSD → クロス円（EURJPY・GBPJPY）
- 価格の単位（円ペアは 1pip=0.01）・最低損切り10pips・コストは通貨ごとに直す（今のコードは EURUSD 固定の所がある）
- 全部の通貨で効く部品（例：日足側）は「環境認識の土台」として採用、EURUSD でしか効かない部品は保留
