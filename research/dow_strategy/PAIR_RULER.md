# 通貨ペアの性格の物差しと、EA の割り当てルール（2026-10-21 確定版 v1）

## 1. 何を共通にして、何を通貨ごとにするか
| 区分 | 中身 | 通貨ごとに変えてよいか |
|---|---|---|
| **共通（絶対に変えない）** | ダウ判定エンジン、損切り＝構造の外＋ATR、H1 スイングトレール（+1R から）、コスト 1.2pips、各 EA のルールと数値 | 変えない |
| **型の選択** | 押し目待ち型（R・T・L・A）／転換追随型（C・J2）のどちらを使うか | **物差しで決める**（EA の成績では決めない） |
| **通貨固有の調整** | 物差しで裏付けのあるものだけ（例：J2 の時間帯 0〜10時） | 前半で選んで後半で確認できたものだけ |

## 2. 物差し（`character2.py`、値動きだけで測る。EA の損益は使わない）

## 3. 判定ルール（固定）
- **転換追随型**：turn_major_h1 と trend_drift が前半・後半とも > 0 → C・J2 を使う
- **押し目待ち型**：bo_h1 が前半・後半とも < 0（高値更新が続かない） → R・T・L・A を使う
- C はどちらの型でも使う（両通貨で PF1.26 以上）
- 判定：EURUSD＝押し目待ち型、USDJPY＝転換追随型

## 4. 物差しと EA 成績のつながり（裏付け）
| EA | 頼っている性格 | 物差し EUR / JPY | EA 成績 EUR / JPY | 整合 |
|---|---|---|---|---|
| J3（H1 本転換についていく） | turn_major_h1 | -0.04 / +0.20 | PF0.79〜0.88 / 1.17→1.28 | ○ |
| J2（切り上げ＋H1 同方向＋0〜10時） | turn_prov+H4+H1 0〜10時 | -0.13 / +0.66 | 前半1.17・後半1.42 / 前半2.24・後半1.59 | ○ |
| R（レンジ逆張り） | range_fade | +0.02 / -0.10 | PF2.26 / 1.34（後半 1.13） | ○ |
| 押し目待ち全般 | bo_h1・trend_drift | 更新が続かない / 続く | EUR で T・L・A 良、JPY で弱い | ○ |
| C（調整ライン抜け） | cl15_break | +0.03 / +0.14 | PF1.43 / 1.26 | △（EA の環境フィルターが効いている） |
| T（ストキャス押し目） | pb_stoch | -0.03 / -0.05 | PF1.45 / 0.77 | ×（物差しでは EUR の強みが見えない。EUR の T は環境条件・長期 MA・トレールの組み合わせで勝っている → EUR 専用の要素が多く、要監視） |

## 5. 新しい通貨を足す手順
1. その通貨の M15 データで `character2.py` を回す（EA は回さない）
2. 3. の判定ルールで型を決める
3. 型の EA を最適化せずに当て、2016-2026 の成績で確認（後半 PF1.2 未満なら見送り）
4. 通貨固有の調整は、物差しに裏付けがあるものだけ、前半で選んで後半で確認
