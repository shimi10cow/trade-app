# 目視レビュー用チャート（EURUSD D1, 2015-2026）

## 見方
- 背景 緑=上昇トレンド / 赤=下降トレンド
- 青い階段線＝その時点の押し安値（上昇中）/戻り高値（下降中）
- 紫の横線＋縦点線＝終値で割れてトレンド転換した水準と転換日
- ▲▼オレンジ＝ダウの安値/高値（HH/HL/LH/LL＝前回同種より高い/低い）
- 青丸＝高値（安値）更新ブレイクの足

## 優先して見てほしい箇所
1. `D1_20250702-20260821.png` 2026-03 の下降転換：戻り高値が 1.208（1月の天井）になっている。1.193（2月の戻り）であるべき？
2. 同じ画像 2025-10〜12：LH/LL が続くが押し安値1.139を割っていないので上昇判定のまま。ここは仮トレンド扱い？
3. その他の期間：転換が「早すぎる／遅すぎる／抜けている」箇所があれば、日付だけ教えてください。
